Security model

Local encryption. Honest limits.

VeilType encrypts messages locally before they are handed to Telegram, WhatsApp, SMS, email, or another app.

VeilType does not run a content server that receives message text.

What to know

  • Both people need VeilType and the shared key.
  • Lost keys cannot be recovered by VeilType.
  • Cryptography cannot prevent screenshots after content is visible.
  • VeilType does not replace device security or safe key sharing.
