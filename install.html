VeilType works as an Android keyboard inside the chat apps you already use.

Before you start

  • Both people need VeilType to open encrypted messages.
  • Both people need the same shared key.
  • Share the key over a channel you trust, separate from the ciphertext when possible.
  • Offline voice typing is planned, not included yet.
First message

Four steps from APK to private text.

01

Install the APK

Download VeilType. Android may ask you to allow installation from your browser or files app.

02

Enable the keyboard

Open VeilType and turn on VeilType Keyboard in Android keyboard settings.

03

Create or receive a key

Create an 8-emoji shared key, or paste and save a key another VeilType user sent to you.

04

Encrypt in any chat

Open a chat, switch to VeilType Keyboard, type your message, and tap Encrypt.

VeilType encrypts locally before the chat app receives the protected text. Keep your shared key private.
