# Product Hunt Demo Script

## Goal

Show VeilType in 30 to 45 seconds with one clear story:

1. Turn on the keyboard
2. Create or receive one 8-emoji shared key
3. Encrypt a message in a normal chat
4. Decrypt it on the second phone

## Demo setup

- 2 Android phones
- VeilType installed on both
- one normal chat app open on both phones
- one 8-emoji shared key already saved on both phones, or ready to be transferred

## 30-second version

### Scene 1
Open the home screen.

Say:
"VeilType is an Android keyboard that encrypts messages before they leave your chat app."

### Scene 2
Tap the setup flow.
Show the key screen and generate an 8-emoji key.

Say:
"You create one 8-emoji shared key, keep it local, and save the same key on the other phone."

### Scene 3
Open Telegram or WhatsApp.
Switch to VeilType Keyboard.
Type a short plaintext message.
Encrypt it.
Send the ciphertext.

Say:
"You still use your normal messenger. VeilType just replaces plaintext with ciphertext."

### Scene 4
On the second phone, copy the ciphertext and decrypt it with VeilType.

Say:
"The other person decrypts it locally. No server, no account, no cloud, no recovery."

## 45-second version

Add one closing screen:
- show the trust strip
- mention local-only 8-emoji shared keys
- mention audio and video capsules as secondary features

Say:
"Text is the launch story. Audio and video capsules follow the same local-only model."

## What not to show first

- advanced key lifecycle actions
- internal format names beyond `TL1` when needed
- experimental setup branches
- too many keyboard toolbar icons
- a failed or slow setup path

## Launch framing

Lead with:
- local-only
- ordinary chat apps
- one 8-emoji shared key
- no new messenger

Do not lead with:
- protocol jargon
- setup edge cases
- recovery questions
- media capsules
